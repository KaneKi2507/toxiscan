Welcome to ToxiScan

ToxiScan is an AI-powered content moderation system built to help communities stay safe. It acts as an automated filter, detecting toxic text, analyzing images for inappropriate content, and identifying objects in media using state-of-the-art machine learning models.

📊 Understanding the Rating Scale (0 to 1)

Our AI models output a confidence score ranging from 0.0000 to 1.0000.

• Closer to 0.0: The content is considered SAFE. The AI is highly confident that the text is polite or the image is appropriate.
• Closer to 1.0: The content is flagged as UNSAFE. A high score means the AI strongly believes the content contains toxicity, hate speech, or NSFW material.

⚙️ Core Features

  • Text Toxicity Detection: Scans sentences for hate speech, insults, and general toxicity using the toxic-bert model.
  • Image Text OCR: Uses Tesseract OCR to read text hidden inside images (like memes or screenshots) and runs it through our toxicity scanner.
  • NSFW Image Detection: Analyzes uploaded images to detect sexually explicit or unsafe visual content.
  • Object Recognition: Identifies and lists everyday objects present within an image.
  • Admin Dashboard: A dedicated control panel to view moderation logs, delete flagged content, and ban malicious users.

🚀 How to Use

  1. Navigate to the Moderation Tools tab at the top.
  2. Choose the tool you want to test (Text, Image OCR, NSFW, or Object Detection).
  3. Enter your text or upload an image file.
  4. Click the action button and wait for the AI to return the JSON prediction scores.
  5. Check the Admin Panel to see how your tested content was logged in the backend.
